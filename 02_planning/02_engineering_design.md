## Problem Summary
Calculated cost for total time during parking session

## Proposed solution
Program that calculates visitors parking cost before or during their parking session

## Technical design

### Inputs
The time the parking session started
Estimated parking time
Car and vehicle description or license plates


**parked hours** (float):the user entered number of hours they anticipate or have parked

### Processing
Register marked vehicle
Time how long parking session lasts
Calculate the total costs of marked parking session 
...
estimated cost = 2.5 * parked hours 
estimated cost = 2.00 * 2.5
...

### Output
Estimated parking cost
Reciept of transaction for user

**estimated** cost (float): the estimated cost per hour!

### Functions
Generalize parking tickets (no vehicle description) What actions belong together?_

## Example interaction

```text
User input: Estimated parking time
Calculate the costs
Print to the user 

Program output: Total costs 
```

## Implementation plan

1. User inputs estimated parking time for 2 hours.
